# 📚 Student Study Planner

A simple and responsive web application that helps students manage their study tasks, subjects, and deadlines.

This project is developed as a simple CPD project using HTML, CSS, and JavaScript.

## 🚀 Features

- Add study subjects
- Add study tasks/topics
- Set task deadlines
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Filter tasks:
  - All Tasks
  - Pending Tasks
  - Completed Tasks
- Display total tasks
- Display pending tasks
- Display completed tasks
- Save tasks using browser Local Storage
- Responsive design for desktop, tablet, and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
